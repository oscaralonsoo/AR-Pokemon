# PokemonAR 🎴

**PokemonAR** es una aplicación de **Realidad Aumentada** desarrollada en **Unity** que combina las cartas físicas de **Pokémon TCG** con modelos 3D e interacciones virtuales.

## 📱 ¿Cómo funciona?

La aplicación utiliza la cámara del dispositivo para reconocer las cartas mediante **Image Tracking** de **AR Foundation**. Gracias a un sistema de **Multiple Image Tracking**, cada carta detectada se identifica y se asocia automáticamente con su Pokémon correspondiente.

Una vez reconocida la carta, se genera el modelo 3D del Pokémon sobre ella. Mediante **Point Clouds** y **Raycasting**, los elementos virtuales se integran con las superficies del entorno real.

## ✨ Funcionalidades

* 📷 Reconocimiento de cartas mediante **Image Tracking**.
* 👾 Generación automática del **Pokémon 3D** correspondiente a cada carta.
* 🔄 **Multiple Image Tracking** para gestionar diferentes cartas.
* 🌍 Integración de los Pokémon en el entorno mediante **Point Clouds** y **Raycasting**.
* 🥎 **Poké Ball interactiva** para capturar Pokémon.
* ⚔️ **Sistema de combates** entre Pokémon.
* ✨ Animaciones y efectos de partículas para mejorar la experiencia.
